(`news-image-20261119`).

## The image

`entry.png` is a 1024x1024 PNG (536,366 bytes) infographic summing up
Thursday 19 November 2026 in six panels:

1. **Myanmar guilty of Rohingya genocide** — the World Court (ICJ) rules 9–6
   that Myanmar committed genocide against the Rohingya.
2. **Trump, Xi & Putin meet in Shenzhen** — the first trilateral summit.
3. **Anthropic IPO: $81 billion** — shares soar 34% on debut.
4. **Denmark OKs Greenland–US pact** — parliament votes 109–0.
5. **COP31 talks stall in Antalya** — fossil fuels cut from the draft deal.
6. **Van Gogh sells for $190 million** — a record price for the artist.

## Run

```sh
python3 main.py
```

Writes the image to `/output/entry.png`. The program only copies bytes
from `entry.png` in this repository: no network, no randomness, so repeated
runs produce byte-identical output.
